# Installation
Windows: Download HUD, extract ZIP, move it to Program files(x84) > steam > steamapps > common > Team fortress 2 > tf > custom

Linux: Download HUD, extract ZIP, ***(Important! install fonts inside resource folder!!)*** then move it to your tf2 folder, for example home/oran/.steam/steam/steamapps/common/Team Fortress 2/tf/custom

the .steam folder is hidden, you need to click View > Show hidden files or press Ctrl + H

Alternative path: /home/oran/.local/share/Steam/steamapps/common/Team Fortress 2/tf/custom/
